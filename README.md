# Learning & Demos

Archivo personal de aprendizaje, preparación y práctica de Valentino Galfré.
Reúne ejercicios, entregas de cursos, proyectos pequeños y demos que muestran
la evolución desde los primeros trabajos hasta las herramientas actuales.

Este repositorio funciona como catálogo y contexto. Los proyectos mantienen su
código e historial en sus repositorios originales; cada enlace indica dónde
consultarlos. El catálogo queda archivado para conservar la historia sin
presentarlo como trabajo activo.

## Cómo leer este archivo

Los repositorios enlazados son las fuentes reales. Este repositorio no copia
ni duplica sus carpetas: mantiene una selección ordenada, la explicación de
qué se aprendió en cada etapa y un punto de entrada para revisar las demos.

Para proyectos actuales y productos en producción, consultar el perfil de
[Valentino Galfré](https://github.com/valentinogalfre) y la organización
[galfredevs](https://github.com/galfredevs).
