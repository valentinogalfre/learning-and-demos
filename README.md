# Legacy Coderhouse

Archivo curado de mis entregas del **Curso de Python — Coderhouse (Comisión 54135, 2024)** y del **Curso de JavaScript — Coderhouse (2026)**.

Los repos originales viven archivados en GitHub para preservar la historia de commits. Este repo paraguas existe para verlos como una sola colección y dar contexto sobre qué era cada uno.

> Estos proyectos son de mis primeros años aprendiendo a programar. Los conservo porque marcan el punto desde el que arranqué — no los uso hoy ni se mantienen.

### 2. Proyecto Final — "Galfre's Zone" (mayo 2024)

**Repo:** [`ProyectoFinalPython-Coderhouse`](https://github.com/valentinogalfre/ProyectoFinalPython-Coderhouse) · archivado
**Re-upload (mismo proyecto en .rar):** [`ProyectoFinal-Python-Coderhouse`](https://github.com/valentinogalfre/ProyectoFinal-Python-Coderhouse) · archivado

Página web para leer y publicar blogs. Sistema de autenticación completo: registro, login, edición de perfil, cambio de contraseña, logout.

Acciones del usuario:
- Publicar blogs
- Visualizar otros blogs
- Editar el perfil
- Cambiar la contraseña
- Cerrar sesión / iniciar sesión

**Stack:** Python · Django · SQLite · HTML5 · CSS3 · JavaScript ES6 · Bootstrap 5.2
**Comisión:** 54135

### 3. Entrega Final — Curso JavaScript (mayo 2026)

**Repo activo:** [`fintrack`](https://github.com/valentinogalfre/fintrack) ⭐

Gestor de finanzas personales en JavaScript vanilla. Cierre del recorrido en Coderhouse, dos años después del primer curso. **No está archivado** porque sigue siendo un proyecto pulido y referenciable.

Permite cargar ingresos y gastos, ver totales del mes, filtrar por tipo/categoría, gráfico de dona en vivo, modo claro/oscuro y persistencia en localStorage.

**Stack:** HTML · CSS · JavaScript ES6 modular · LocalStorage · Chart.js · SweetAlert2 · Toastify · Day.js
